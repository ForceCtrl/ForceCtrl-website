Force as an Interface for Humanoid Loco-Manipulation

Paper Video Code upon acceptance

Abstract

Humanoid motion trackers know where the body should be, not how hard it should act on the world. Ctrl-F adds that missing channel: an explicit 3-D force command at each designated force body, a hand or a foot in our experiments. A motion–force tracker, trained without any object, realises the commanded force while following the reference motion, and a high-level planner chooses the command online from object state and proprioception. On a Unitree G1 this drags, pushes, raises and kicks loads up to 20 kg where a force-blind tracker moves nothing, and it keeps going when weight is added mid-task.

Method

The interface is a reference motion plus a force command. A low-level tracker follows the motion and realises whatever force it is commanded at each designated force body; a high-level planner decides that force. Neither observes a force sensor or the object's mass.

Stage 1: train the tracker to realise a commanded force

Training has no objects. Each episode samples a 3-D force command for a force body and applies the opposite wrench to it. The only way to hold the reference pose under that wrench is to push back with exactly the commanded force, so the tracker learns a force channel without ever touching a thing.

The trained tracker under an external force: the hand sinks under the wrench alone and recovers once the matching command is given.

On hardware, the commanded force measured on a crane scale.

Stage 2: learn what force to command

With the tracker frozen, a planner reads the object state and the robot's proprioception and outputs one force per force body. It starts from an analytical wrench-allocation model and is refined by reinforcement learning scored on the object's motion, so the command adapts when the load changes.

The planner in simulation, at half speed. The box gains 2.5 kg mid-hold; the commanded force (green) rises from 74 to 126 N within a second and the box stays where the reference puts it. No mass or force is observed.

Hardware

Unitree G1 with onboard sensing and AprilTag object pose. SONIC, a general motion tracker with public G1 weights and no force channel, is the baseline; it runs the same clips on the same objects. Loads are the weight added to the object.

Simulation

Nine tasks in three families: hands, feet, and hands with feet. One low-level and one high-level policy per family. Object mass is randomised between episodes and changed inside them.

Load sweep. Force-blind arms fail within a quarter of the nominal mass; Ctrl-F stays above 90 % completion across the range.

A mass step mid-episode. The commanded force follows the load, with neither mass nor force observed.
